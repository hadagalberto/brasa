# Credits

Brasa is built entirely from open-source components and assets created for this
project. No stock photography, no external image hotlinks, no tracking.

## Fonts (SIL Open Font License 1.1)

Self-hosted through [Fontsource](https://fontsource.org), subset to latin and
latin-ext, shipped as variable fonts with `font-display: swap`:

- [Fraunces](https://github.com/googlefonts/fraunces) — editorial display face,
  optical sizing and italic. SIL OFL 1.1.
- [Geist](https://vercel.com/font) — interface and body grotesk. SIL OFL 1.1.
- [Geist Mono](https://vercel.com/font) — eyebrows, metadata and code. SIL OFL 1.1.

License texts ship with the font packages in `node_modules/@fontsource-variable/*`.

## Runtime and build (MIT)

- [Astro](https://astro.build) — static site generator, Content Collections,
  View Transitions. MIT.
- [Tailwind CSS v4](https://tailwindcss.com) — CSS-first `@theme` tokens. MIT.
- [MDX](https://mdxjs.com) — authoring format. MIT.
- [Expressive Code](https://expressive-code.com) — syntax highlighting, copy
  button and code frames. MIT.
- [Pagefind](https://pagefind.app) — static search index. MIT.

## Testing and auditing

- [Playwright](https://playwright.dev) — end-to-end browser tests. Apache-2.0.
- [axe-core](https://github.com/dequelabs/axe-core) — accessibility auditing.
  MPL-2.0.
- [Lighthouse CI](https://github.com/GoogleChrome/lighthouse-ci) — performance,
  accessibility, best-practices and SEO assertions. Apache-2.0.
- [resvg](https://github.com/RazrFalcon/resvg-js) and
  [satori](https://github.com/vercel/satori) — build-time OG image rendering.
  Apache-2.0 / MIT respectively.
