## Conteúdo e busca

<Accordion
  items={[
    {
      q: 'Onde escrevo posts e documentação?',
      a: 'Arquivos MDX em src/content/blog e src/content/docs. O frontmatter é validado por esquemas Zod em src/content.config.ts; o nome do arquivo se torna o slug da URL.',
    },
    {
      q: 'Por que o build do meu MDX falhou na linha 9?',
      a: 'Quase sempre por um import colocado junto ao frontmatter. O YAML termina no segundo --- e os imports devem vir depois dele. npm run build executa scripts/verify-mdx.mjs primeiro e imprime o arquivo e a linha exatos.',
    },
    {
      q: 'Como adiciono um autor?',
      a: 'Adicione um arquivo JSON em src/content/authors com name, role, bio e links opcionais. Referencie o nome do arquivo (sem .json) no campo author de um post. Os avatares são iniciais geradas, então nenhuma imagem é necessária.',
    },
    {
      q: 'Como funciona a busca?',
      a: 'O Pagefind gera um índice estático em dist/pagefind durante npm run build. A caixa de diálogo abre com Ctrl/⌘+K ou /, carrega o índice de forma preguiçosa na primeira abertura e aceita navegação pelas setas do teclado.',
    },
    {
      q: 'Por que a busca diz que o índice está indisponível?',
      a: 'Você provavelmente executou astro build diretamente em vez de npm run build, ou está no astro dev, onde nenhum índice existe. Faça o build com o script npm e sirva com npm run preview.',
    },
  ]}
/>

## Build e deploy

<Accordion
  items={[
    {
      q: 'Qual versão do Node preciso usar?',
      a: 'Node 20 ou mais recente; a CI usa Node 22. Fixe a mesma versão nas configurações do seu host.',
    },
    {
      q: 'Por que PAGES_BASE_PATH é separado de SITE_URL?',
      a: 'SITE_URL é a origem absoluta usada para links canônicos e feeds. PAGES_BASE_PATH é o subcaminho da URL a partir do qual o site do projeto é servido. Um repositório no GitHub Pages em /brasa precisa de ambos.',
    },
    {
      q: 'Quais hosts são suportados?',
      a: 'Qualquer host estático. O repositório inclui workflows para GitHub Pages e CI; o guia de deploy também cobre as configurações de Vercel, Netlify e Cloudflare Pages.',
    },
    {
      q: 'Como verifico um deploy?',
      a: 'Verifique se o alternador de tema persiste, se Ctrl+K retorna resultados, se os feeds carregam, se uma URL OG retorna um PNG e se uma URL inexistente renderiza a página 404 personalizada com status 404.',
    },
  ]}
/>
