O Brasa gera um diretório `dist/` totalmente estático. Não há runtime de servidor, banco de dados nem caminho de renderização específico por ambiente. Se um host consegue servir arquivos, ele consegue hospedar o Brasa.

## O contrato de build

```bash
npm ci
npm run build
```

`npm run build` executa três etapas em ordem:

1. `node scripts/verify-mdx.mjs` — valida todo bloco de frontmatter MDX.
2. `astro build` — renderiza rotas, feeds e imagens OG, e executa os schemas de conteúdo do Astro.
3. `pagefind --site dist` — grava o índice de busca em `dist/pagefind/`.

<Callout variant="danger" title="Não pule a etapa do Pagefind">
  Executar `astro build` diretamente produz um site em que o diálogo de busca abre mas reporta um
  índice indisponível. Sempre use `npm run build`, ou adicione o comando do Pagefind explicitamente
  à etapa de build do seu host.
</Callout>

## Caminhos base e links

Toda URL interna passa por `import.meta.env.BASE_URL`: links de navegação, links do rodapé, alternâncias de feed, caminhos de imagem OG, o favicon e a URL do módulo do Pagefind. É por isso que a mesma fonte gera em `/` e em `/brasa/` sem uma auditoria de links.

<Callout variant="warning" title="Um caminho base errado falha silenciosamente">
  O HTML ainda renderiza, mas CSS, fontes, imagens e o índice de busca dão 404. Após mudar o caminho
  base, abra o site publicado e verifique o console do navegador, depois execute o teste Playwright
  "todas as URLs e assets internos resolvem" no preview com o mesmo `PAGES_BASE_PATH` definido.
</Callout>

## Cache

Assets com fingerprint em `dist/_astro/` podem ser cacheados de forma imutável com segurança. Imagens OG geradas trazem `Cache-Control: public, max-age=31536000, immutable` nos headers do endpoint, mas um host estático serve o arquivo diretamente — defina um tempo de cache longo para `/og/` na config do host se quiser o mesmo comportamento.

`pagefind/` deve ser cacheado com o restante da saída estática e invalidado a cada deploy. Como o índice é endereçado por conteúdo internamente, um índice desatualizado não pode ser carregado parcialmente.

## Verificando o deploy

```bash
SITE_URL=https://your-domain.example PAGES_BASE_PATH=/ npm run build
npm run preview
npm test
```

Depois verifique, no host em produção: o alternador de tema persiste após recarregar sem flash, `Ctrl+K` retorna resultados, `/rss.xml` e `/feed.json` carregam, uma URL OG retorna um PNG, e a página 404 renderiza com seu próprio código de status.
